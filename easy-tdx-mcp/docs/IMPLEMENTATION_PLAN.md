# 实施计划

## 阶段 0：基线与许可

- 锁定上游提交 `e533b70`（项目元数据 1.20.6）。
- 复制源码到项目内 `src/easy_tdx`，保留上游 LICENSE/NOTICE，并记录 fork 来源。
- 删除 `easy-tdx` 运行时依赖，修正发行包版本读取与项目内状态目录。

## 阶段 1：MCP 基础设施

- 建立统一枚举、Pydantic 输入/输出模型、DataFrame/Dataclass/Enum JSON 序列化。
- 建立客户端生命周期、连接策略、异常映射、分页/上限和日志策略。
- 提供能力清单、指标目录、策略目录、因子目录等 resources。

## 阶段 2：在线数据工具

- 标准协议：证券、K 线、分时、逐笔、除权、财务/F10、板块、资金流。
- Mac 协议：复权行情、分类报价、板块分析、竞价、异动和证券信息。
- 扩展市场：港股、美股、期货的列表、报价、K 线、分时与逐笔。
- 独立数据源：巨潮公告、新浪研报。

## 阶段 3：研究计算工具

- 34 个技术指标与内联 OHLCV 计算。
- 缠论单级别/多级别分析。
- 19 个内置策略回测、网格优化、组合回测和绩效归因。
- 因子分析、选股扫描、组合权重优化与再平衡。

## 阶段 4：本地与有副作用能力

- 离线通达信文件探测与读取。
- 文件下载、日线/分钟线增量写入与同步；增加目标路径安全检查。
- 实时轮询改为有界采样，避免永久占用 MCP 请求。

## 阶段 5：验证与交付

- 单元测试：模型、序列化、参数边界、错误映射、假客户端调用。
- MCP 协议测试：initialize、tools/list、resources/list、代表性 tool/call。
- 无网络测试与可选 live smoke test 分离。
- 核对公共 API/CLI/指标/策略/因子映射表，运行 pytest、ruff、打包安装测试。
- 同步到 `D:\claude\openrich-mcp\easy-tdx-mcp`。

## 完成定义

每一阶段只有在代码、测试、文档和能力映射同时完成后才算完成。网络环境不可用时，协议编解码和服务层必须可用假传输验证；live smoke test 标记为可选而不能阻塞单元测试。
